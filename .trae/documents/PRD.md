## 1. 产品概述

伯明翰桌游（Brass: Birmingham）小助手网页版，专为德式桌游玩家在游戏过程中计算花费、决定顺位、管理资金与收入轨而设计。
- 解决问题：替代纸笔记录每回合花费，自动按花费升序排定下一回合顺位，自动结算收入，支持回合回滚
- 目标用户：德式桌游玩家，追求简洁、高效、无干扰的工具体验
- 价值：把规则计算交给工具，玩家专注策略与思考

## 2. 核心功能

### 2.2 功能模块

1. **设置页**：选择 2-4 名玩家、配置玩家颜色（红/黄/紫/白）、随机分配初始顺位、一键分配初始资金、进入游戏
2. **游戏主页**：玩家卡片（金钱、本回合花费、收入轨位置）、加减按钮快速记录花费、收入轨可视化、结束回合、回滚上一回合

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 设置页 | 玩家数量选择 | 2/3/4 人按钮切换，决定后续玩家槽位数量 |
| 设置页 | 玩家颜色配置 | 红/黄/紫/白四色，按数量自动分配，玩家可点击槽位切换颜色 |
| 设置页 | 随机顺位 | 一键随机打乱玩家顺位，显示 1st/2nd/3rd/4th |
| 设置页 | 初始资金分配 | 根据人数自动填入默认值（2P=$30、3P=$20、4P=$17），可手动微调 |
| 设置页 | 开始游戏按钮 | 锁定配置进入游戏主页 |
| 游戏主页 | 顶部状态栏 | 显示当前回合数、当前顺位提示（谁先谁后） |
| 游戏主页 | 玩家卡片 | 每张卡片显示：玩家色块、顺位编号、剩余金钱、本回合花费、收入轨等级 |
| 游戏主页 | 花费增减按钮 | 每张卡片配 ±$1 / ±$5 快速按钮，记录本回合花费 |
| 游戏主页 | 收入轨 | 显示当前收入等级（0-100），支持 +1/-1 调整（开发/售货等动作推进） |

| 游戏主页 | 结束回合结算 | 按本回合花费升序排定新顺位（花费少者先），按收入等级发放收入到金钱 |
| 游戏主页 | 回滚 | 撤销上一回合的全部变更（顺位、金钱、收入、花费清零） |

## 3. 核心流程

启动 → 设置页选择人数 → 配置玩家颜色 → 随机顺位 → 确认初始资金 → 进入游戏主页 → 各玩家在自己的卡片上 ±花费、±收入轨 → 点击「结束回合」→ 系统按花费升序排顺位（同花费保持原顺序）→ 按收入等级给每名玩家发放收入 → 进入下一回合 → 重复
任意时刻可点击「回滚上一回合」回到上一回合结束时的状态。

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：移动端单屏优先，德式桌游式工业简洁风，深色背景凸显红黄紫白玩家色
- **主色**：深炭灰 `#1a1a1a` 背景 + 米白 `#f5f0e6` 文字；玩家色：红 `#c83232`、黄 `#e0b020`、紫 `#7b3fa0`、白 `#e8e8e8`
- **按钮风格**：大尺寸圆角矩形（最小高度 56px），±$1 与 ±$5 颜色区分（加=暖色、减=冷色），点击有触感反馈
- **字体**：显示字体用 `Space Grotesk` 或 `Bebas Neue`（数字醒目），正文用 `Inter`；数字采用等宽数字（tabular-nums）便于对齐
- **布局**：垂直列表式玩家卡片，底部固定操作栏；移动端单屏（375px-430px 宽）完整展示
- **图标/emoji**：极简，仅用 ▲▼± 数字符号，不使用花哨插画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 设置页 | 人数选择 | 3 个大圆角按钮 2/3/4，选中态描边+填充 |
| 设置页 | 玩家槽位 | 横向排列玩家色块 + 顺位徽章，点击切换颜色 |
| 设置页 | 顺位随机按钮 | 大按钮，点击触发随机动画 |
| 设置页 | 初始资金输入 | 每位玩家一个大数字输入框，默认值预填 |
| 设置页 | 开始游戏 | 底部全宽主按钮 |
| 游戏主页 | 顶栏 | 回合数 + 顺位排序提示 |
| 游戏主页 | 玩家卡片 | 色块头 + 顺位编号 + 金钱大数字 + 本回合花费 + 收入轨等级 + ±$1/±$5 按钮 + 收入轨 ±1 按钮 |
| 游戏主页 | 底部操作栏 | 左「回滚上一回合」（次要）右「结束回合」（主要）两大按钮，全宽固定 |

### 4.3 响应式

- **移动端优先**：设计基准 375×667（iPhone SE）到 430×932（iPhone 14 Pro Max），确保 4 人模式下所有信息单屏可见
- **桌面端**：居中显示最大宽度 480px 的「手机框」，模拟移动端体验
- **触摸优化**：所有可点击元素最小 44×44pt，按钮间距 ≥ 8px，防误触
